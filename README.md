# swy4x.github.io

Personal cybersecurity portfolio website.

## Publish
1. Create a public GitHub repository named `swy4x.github.io`.
2. Upload `index.html` to the repository root.
3. In Settings → Pages, select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Save and wait for GitHub Pages to publish at https://swy4x.github.io/.

## Google Search Console
After Google gives you its unique HTML verification file, upload that exact file to this repository's root (do not rename it), wait for the Pages deployment, then verify the site URL `https://swy4x.github.io/`.

The verification file is unique to your Search Console property and cannot be generated in advance.
